Cookie and Browser Storage Policy

This policy explains how the Study Vault uses browser storage, offline cache and consent preferences. No analytics or session-replay SDK is installed. Student study features work without an account and use local browser storage by default.

Your choice matters. Use the persistent “Privacy settings” control on any page to review or change optional preferences. Rejecting optional categories does not block the public resource catalogue or local-only study features. Account sign-in, EduBot and administrator Supabase remain unavailable until Optional external services is enabled.

1. Necessary storage

  • Local study data: saved materials, syllabus progress, tasks, study-session records, Study Tools preferences and theme settings are stored in localStorage on this device. They are not automatically synced to a server and may be erased if site data is cleared.
  • Service-worker cache: stores selected site files for offline access. It is application cache, not an advertising cookie.
  • Consent preference: the site stores your versioned category choices and update timestamp in localStorage under icseMasterClassConsentV1.

2. Optional analytics

This website does not currently run an analytics SDK. No Hotjar, Microsoft Clarity or other session-replay SDK is installed. Analytics remains off unless you explicitly opt in. Selecting it does not currently activate tracking; any future analytics must check this preference before loading. Necessary hosting, the public catalogue and core presentation assets may still make network requests.

\n

3. Optional external services

EduBot is an optional AI feature. Its shared API client is loaded only after you enable “Optional external services” in Privacy settings and then interact with EduBot. When used, your question and recent conversation context (up to 10 messages, including user and assistant messages) are sent to the EduBot API hosted by Vercel. The API uses Google Gemini as its primary provider and may use Groq as a fallback when Gemini is unavailable. The same preference gates Firebase Authentication until you choose an account action and gates the administrator-only Supabase SDK until an administrator manually chooses to connect. Rejecting this category leaves the catalogue and local-only study tools available, but account sign-in, EduBot and administrator Supabase cannot start.

\n

4. Core third-party requests

The public catalogue retrieves its published resource data from Google Sheets. The catalogue and dashboard currently request Tailwind CSS and Font Awesome presentation assets from public CDNs so the existing utility-based layout and icons can render. These are treated as core presentation dependencies, not analytics or session replay, and may receive request metadata such as an IP address even when optional categories are rejected. The 404 page is self-contained and uses a native system font stack. Google Fonts are not loaded. Firebase Authentication is loaded only after explicit Optional external services consent and a user account action. External YouTube and Telegram destinations load only when you choose to open those links.

\n

5. Changing or clearing choices

Choose “Privacy settings” at the bottom-left of a page to reopen the preference panel. You can accept all optional categories, reject them, or save a custom choice. You can also clear local site data through your browser settings, but doing so may sign you out, erase local study data and remove offline files. Clearing browser data does not delete a Firebase Authentication account.

6. Region preferences

The preference panel offers an optional self-selected region profile (India, EEA/UK, California/United States, another region, or not sure). This value is stored with the consent record to help the operator understand which notice may be relevant. The website does not infer your location from your IP address for this setting, and your selection does not determine whether a law applies. The same conservative optional opt-in defaults are used for every profile until region-specific requirements are reviewed and configured.
