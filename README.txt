# ICSE MasterClass Portal Starter

This is a new `portal.html` page intended to be added to the existing public repository:
https://github.com/icse-cbse-10-12/icse-class-10-materials

It does not replace `index.html` or remove existing study materials. After uploading `portal.html`, open:
https://icse-cbse-10-12.github.io/icse-class-10-materials/portal.html

## Upload on Android
1. Open the repository link above in your browser and sign in to GitHub.
2. Tap **Add file** → **Upload files**.
3. Upload `portal.html` from this ZIP (extract the ZIP first in your Files app).
4. Tap **Commit changes**.
5. Open the portal URL above.

AI tutor, Google/email authentication and private admin uploads are intentionally shown as requiring secure backend setup. Do not put API keys in HTML or public GitHub files.
