# ICSE MasterClass — SEO, GEO, AIO and AXO content map

Updated: 11 November 2026

## Scope and terminology
- SEO: Search Engine Optimisation — crawlability, indexation, page intent, useful content, internal links and descriptive metadata.
- GEO: Generative Engine Optimisation — make facts, entities, authorship, evidence and source links easy for answer engines to understand and cite.
- AIO: AI Optimisation — structure accurate, self-contained explanations and machine-readable metadata for AI-assisted discovery. This does not guarantee inclusion in AI answers.
- AXO: Answer Experience Optimisation — answer the student's question quickly, then provide context, steps, caveats and primary sources.

The site is an independent educational resource directory. It is not affiliated with, authorised by or endorsed by CISCE. Never imply official status.

## On-page rules
1. One clear primary search intent per page; do not make every page target the same head term.
2. Write titles for humans first; keep the main topic near the start and brand at the end.
3. Use one descriptive H1, meaningful H2s and natural synonyms. No keyword-density targets or exact-match stuffing.
4. Add canonical URLs, concise descriptions, Open Graph metadata and accurate BlogPosting, Blog or FAQPage structured data only where visible content supports it.
5. Each factual article identifies publisher, publication/update dates, evidence and primary sources.
6. Link homepage to blog and FAQs; link articles back to the Study Vault and related help pages.
7. Link official claims to CISCE. Label independent summaries and selected date lists clearly.
8. Do not generate fake reviews, ratings, author credentials, exam predictions, search volumes or guaranteed outcomes.

## GEO / AIO / AXO answer format
Start with a direct 1–2 sentence answer. Add a date, scope or eligibility caveat. Follow with a concise table or steps. Link to the original authority and state when it overrides the summary. Keep visible FAQs consistent with structured data. Keep facts consistent across the homepage, blog, FAQ page and llms.txt.
